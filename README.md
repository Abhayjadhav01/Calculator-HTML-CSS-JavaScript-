# Calculator - HTML, CSS & JavaScript

A modern, responsive calculator built using **HTML**, **CSS**, and **Vanilla JavaScript**. This project performs basic arithmetic operations with a clean user interface inspired by modern calculator applications.

## 🚀 Features

- ➕ Addition
- ➖ Subtraction
- ✖ Multiplication
- ➗ Division
- 🧹 Clear (AC)
- ⌫ Delete (DEL)
- 📱 Responsive Design
- 🎨 Modern Dark UI
- ⚡ Fast and Lightweight
- 💻 Built with Pure HTML, CSS & JavaScript

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

## ▶️ How to Run

1. Clone the repository

```bash
git clone https://github.com/Abhayjadhav01/Calculator-HTML-CSS-JavaScript-.git
```

2. Open the project folder

```bash
cd Calculator-HTML-CSS-JavaScript-
```

3. Open `index.html` in your browser.
